# Ghi chú học tập

Thư mục này là của bạn. Mỗi buổi học một file, đặt tên theo dạng:

```
2026-09-09-co-ban-04-claude-md.md
```

Dùng [`_template.md`](_template.md) làm khung, hoặc chạy `/ghi-chu-buoi-hoc`
để Claude sinh ghi chú từ chính hội thoại của buổi đó.

Skill `/on-tap` đọc danh sách file ở đây để biết bạn đang học tới đâu, nên
việc đặt tên file nhất quán có ích thật sự, không chỉ để gọn mắt.

Điều đáng ghi nhất không phải là tóm tắt lý thuyết — cái đó đã có trong `docs/`.
Đáng ghi là: **chỗ bạn làm sai**, **chỗ tài liệu không khớp thực tế**, và
**cấu hình bạn đã thử và giữ lại**.
