# Nguồn tài liệu

Tài liệu trong repo này được viết dựa trên tài liệu chính thức. Claude Code
phát hành rất nhanh, nên khi có gì không khớp, **tài liệu gốc là đúng**.

## Điểm vào

| Nguồn | Địa chỉ |
| --- | --- |
| Trang tài liệu | https://code.claude.com/docs/en/overview |
| Chỉ mục đầy đủ cho máy đọc | https://code.claude.com/docs/llms.txt |
| Changelog | https://code.claude.com/docs/en/changelog |
| What's new | https://code.claude.com/docs/en/whats-new |

`llms.txt` liệt kê toàn bộ URL tài liệu. Bản thân Claude Code đọc được file này,
nên bạn có thể nhờ nó tra cứu trực tiếp.

```text
phù hợp để chạy lint sau khi sửa file
```
