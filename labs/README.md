## Cách làm lab

1. Làm trên **dự án thật của bạn**, không phải repo này. Cấu hình chỉ có giá
   trị khi nó giải quyết vấn đề bạn thật sự gặp.
2. Làm xong thì chạy `/ghi-chu-buoi-hoc` để lưu lại vào `notes/`.
3. Nếu lab không chạy như mô tả, ghi lại điều đó — tài liệu có thể đã cũ so
   với phiên bản Claude Code của bạn.
